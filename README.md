# NIRA Digital Policy Feedback

Research project and dashboard for public feedback on Somalia’s National ID policy and NIRA services.

The dashboard is the Streamlit app `dashboard/streamlit_app.py`. From this folder:

```
python -m streamlit run dashboard/streamlit_app.py
```

Repository: https://github.com/Raggeh/NIRA_CASE_STUDY_PROJECT

The saved results are in this repository. The raw comment file and the annotation workbook are not included, because some comments contain phone numbers. The dashboard reads the saved result tables and does not refit the models.
